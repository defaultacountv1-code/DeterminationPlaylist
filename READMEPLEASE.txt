The discord status only works once you set up a Discord application with the steps below:

- Go to discord.com/developers/applications and create a New Application. Its name is what appears after "Listening to", so something like "Determination Playlist" works well.
- Copy its Application ID.
- Under Rich Presence -> Art Assets, upload soul.png and name it exactly soul.
- In the app, open Settings -> Discord status, paste the ID under Application ID and turn the "Discord" button on.
